## Why

Накопленная база организаций с историей взаимодействий существует в CSV-выгрузке
(~400 организаций и ~4,6 тыс. записей взаимодействий); формат файла объявлен
нормативно в спецификации `organizations-import`.
Ручной перенос тысяч записей нецелесообразен и ошибкоопасен. Нужен управляемый
импорт в администрировании: загрузка файла с проверкой структуры, пакетная
обработка с видимым прогрессом и интерактивное разрешение проблемных данных
(нераспознанные даты, дубликаты названий) с продолжением строго с места
остановки — без повторного создания уже сохранённых записей.

## What Changes

- В выпадающем списке «⚙ Админ ▾» появляется пункт «Импорт организаций»,
  ведущий на новую страницу загрузки и обработки CSV-файла. Возможность доступна
  только администратору (`ROLE_ADMIN`).
- Сервис импорта проверяет заголовки столбцов загруженного файла на соответствие
  заявленной структуре; при несоответствии загрузка отклоняется с понятным
  перечнем ожидаемых заголовков.
- Обработка выполняется пакетами не более 25 организаций; прогресс «сколько
  сохранено / сколько всего» отображается progress bar на странице и обновляется
  polling.
- Каждая строка сохраняется отдельной транзакцией: при ошибке строка не
  сохраняется, уже сохранённые строки пакета остаются, обработка
  останавливается, ошибка отображается, а импорт можно продолжить
  с последней обработанной позиции.
- Статусы не используются: прогресс определяется числом обработанных строк —
  пока processedRows < totalRows, импорт можно продолжить (в том числе после
  перезагрузки страницы), иначе действий нет.
- CSV-файл можно заменить повторной загрузкой, пока не все строки обработаны:
  новый файл проверяется, а число обработанных строк сохраняется — обработка
  продолжается с той же позиции в новом файле.
- Два интерактивных условия остановки; после подтверждения пользователем импорт
  продолжается с места остановки:
  1. нераспознанная дата в поле, порождающем звонок, — предложение отредактировать
     значение в поле (или пропустить запись с предупреждением);
  2. дубликат названия организации — выбор «слить с существующей организацией»
     (её контакты и звонки дополняют существующую карточку) или «создать новую».
- Каждая непустая строка столбца «Взаимодействия» порождает отдельный совершённый
  звонок (`Call`) с датой из строки и временем 12:00 дня.
- Импортированные организации не получают назначений групп (импорт — область
  администратора, ADR-0011); модель доступа к организациям, контактам и звонкам
  не изменяется.
- Структура входного CSV объявлена в спеке `organizations-import` («Формат
  CSV-файла»): колонки и их назначение, многострочные ячейки и кавычки, варианты
  дат взаимодействий, плейсхолдеры и игнорируемые колонки; файл-образец в
  репозитории не хранится.

## Capabilities

### New Capabilities

- `organizations-import`: загрузка CSV-файла администратором, проверка заголовков,
  пакетная обработка до 25 организаций (пакет — только порция для проверки,
  отдельная транзакция на строку), polling прогресса, продолжение с обработанной
  позиции при ошибке строки, замена CSV-файла с сохранением прогресса, пауза
  с редактором поля при нераспознанной дате и диалогом выбора при дубликате
  названия, отображение итогов импорта.

### Modified Capabilities

- `web-interface`: нормативный состав пунктов выпадающего списка «⚙ Админ ▾»
  расширяется пунктом «Импорт организаций» (страница новой возможности
  `organizations-import`).

## Impact

- **Сущности**: импорт создаёт/дополняет `Organization`, `Contact`, `Call` в
  рамках существующих моделей (ADR-0004, ADR-0011); требований к существующим
  возможностям `organizations`, `calls`, `contacts` изменение не вносит.
- **Доступ**: новая страница и JSON-эндпоинты — только `ROLE_ADMIN`; менеджеры
  не затронуты.
- **UI**: шапка (выпадающий список «Админ») и новая страница в компонентах,
  заданных web-interface.
- **Границы скоупа (допущения)**: файл-образец в репозитории не хранится и не
  автозагружается — он подаётся через форму загрузки; формат объявлен в спеке;
  статусы не используются: продолжение доступно, пока processedRows < totalRows,
  а файл никогда не удаляется; сообщение об ошибке показывается в момент
  возникновения и не хранится в сессии; уже созданные записи не откатываются;
  одновременно активна ровно одна сессия импорта; повторный импорт того же файла
  приводит к остановке на каждом совпадении названия (разрешается диалогом
  слияния); историческим звонкам импорта проставляется `madeBy` = администратор,
  запустивший импорт, без отметок результата; колонки «Следующий контакт»,
  «Для чего звонок?» и «Текущее состояние» в звонки не превращаются; `name` и
  `annualPlan` длиннее 255 символов обрезаются; конвертация «Учились у нас»
  в текстовое поле — отдельное изменение; BREAKING-изменений нет.
