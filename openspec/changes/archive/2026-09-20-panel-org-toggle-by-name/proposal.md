## Why

На панели организаций раскрытие контактов и звонков происходит через отдельную ссылку-аккордеон «Звонки и контакты организации» внутри второй строки таблицы. Это создаёт лишний визуальный шум и требует от пользователя дополнительного действия (клик по summary внутри раскрытой строки). Более интуитивный паттерн — раскрытие по клику на любую часть строки организации, что убирает промежуточный элемент и делает взаимодействие прямым.

## What Changes

- Удаляется отдельная ссылка-раскрытие «Звонки и контакты организации» (элемент `<summary class="org-details__summary">`) из раскрытой строки организации.
- Вся строка организации становится кликабельной областью для раскрытия/сворачивания секции контактов и звонков.
- Клик по любой части строки организации (название, сфера деятельности, даты звонков) раскрывает/сворачивает секцию контактов и звонков этой организации.
- Кнопка «Изменить» организации остаётся отдельной и продолжает открывать модальное окно редактирования (клик по кнопке не должен раскрывать строку).
- Визуальный индикатор раскрытия (треугольник ▸) добавляется к названию организации.
- При сохранении контакта или добавлении звонка происходит переход на панель с выделенной организацией, и эта организация автоматически раскрывается (параметр `highlight` в URL дополняется автоматическим раскрытием секции).

## Capabilities

### New Capabilities

_Нет новых возможностей._

### Modified Capabilities

- `dashboard`: изменяется способ раскрытия контактов организации — вместо клика по отдельной ссылке-аккордеону «Звонки и контакты организации» раскрытие происходит по клику на любую часть строки организации.

## Impact

- **Шаблоны**: `templates/home/partials/_organizations_table.html.twig` — удаление `<summary>` элемента, добавление data-атрибута к строке для JS-обработчика.
- **Стили**: `assets/scss/pages/dashboard-orgs.scss` — добавление индикатора раскрытия (▸) к названию, стили для cursor pointer на строке, удаление стилей `.org-details__summary`.
- **JavaScript**: `assets/js/organization-modal.js` — добавление обработчика клика по строке организации для управления `<details>` (с исключением кликов по кнопке «Изменить»), автоматическое раскрытие строки при наличии параметра `highlight`.
- **E2E тесты**: обновление селекторов в `e2e/tests/dashboard-organizations.spec.ts`, `e2e/tests/calls-crud.spec.ts`, `e2e/tests/call-result.spec.ts`, `e2e/tests/contact-ismain.spec.ts` — замена клика по `summary.org-details__summary` на клик по строке организации.
