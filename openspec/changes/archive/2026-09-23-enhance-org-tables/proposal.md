## Why

Таблицы организаций на панели, в скрытых организациях и в составе группы не показывают ключевые атрибуты (УНП, дата создания, создатель, отрасль), не сортируются по заголовкам и не дают зафиксировать ширину колонок; панель дублирует сферу деятельности отдельной колонкой, хотя описание и отрасль логичнее держать в раскрывающейся строке `org_details`.

## What Changes

- Добавить необязательное поле **УНП** (белорусский налоговый ID) в карточку организации: форма, quick-edit модалка, строка `org_details`; не выводить в таблице панели.
- **BREAKING**: переименовать столбец `has_used_services` → `courses_attended` и изменить тип с boolean на свободный текст (VARCHAR(255) DEFAULT NULL); без миграции продовых данных — MySQL приведёт `0`→`'0'`, `1`→`'1'`; обновить фикстуры примерами названий курсов.
- Добавить `Organization.created_by` (создатель организации); порядок полей: `created_by` последним, затем `created_at`/`updated_at`; поправить фикстуры; БД можно менять без side-effects миграции.
- При удалении менеджера: группы — выбор переназначения/удаления; организации — автоматическое переназначение создателя текущему администратору (примечание на странице подтверждения).
- Таблица **«Скрытые организации»**: добавить колонки «Дата создания» и «Отрасль».
- Таблица **«Состав группы»**: добавить «Дата создания» и «Создатель» (создатель организации); заголовки сделать сортируемыми (Название, Отрасль, Дата создания, Создатель), сортировка по умолчанию — Название ASC.
- Общее правило ширины колонок для таблиц организаций: колонка названия фиксированная/sticky с максимально возможной шириной, остальные — статические вычисленные ширины (панель, скрытые организации, состав группы).
- Таблица на панели: **удалить** колонку «Сфера деятельности» и её сортировку; описание организации и сферу деятельности перенести в раскрывающуюся строку `org_details`.
- Порядок содержимого `org_details` сверху вниз: Описание → Сфера деятельности → Последний звонок → Все звонки → Контакты → кнопки «Добавить звонок» и «Добавить контакт» в самом низу строки.

## Capabilities

### New Capabilities
- (нет — все изменения ложатся на существующие возможности)

### Modified Capabilities
- `organizations`: необязательное поле УНП; `hasUsedServices` → `coursesAttended` (столбец переименован, тип bool→text, BREAKING); поле-ссылка `created_by` (создатель организации).
- `organizations/crud`: поля формы и quick-edit модалки — УНП, текстовый «Учились у нас» (`coursesAttended`); отображение создателя.
- `organization-hiding`: в реестре скрытых организаций новые колонки «Дата создания» и «Отрасль».
- `organization-groups`: таблица состава группы — колонки «Дата создания», «Создатель»; сортируемые заголовки (Название, Отрасль, Дата создания, Создатель), default — Название ASC.
- `dashboard`: из таблицы панели убрана колонка (и сортировка) «Сфера деятельности»; в `org_details` — описание, строка метаданных (сфера деятельности, УНП, курсы), последний звонок, все звонки, контакты, кнопки действий внизу; правило фиксированной/max ширины колонки названия и статических остальных.
- `web-interface`: общее соглашение о ширинах колонок в таблицах организаций (название — max/fixed, остальные — статические).
- `user-delete`: группы — выбор переназначения/удаления; организации — автоматическое переназначение создателя текущему администратору (примечание на странице подтверждения).

## Impact

- Сущность `Organization` (Doctrine): переименование `hasUsedServices` → `coursesAttended` (столбец `has_used_services` → `courses_attended`, тип bool→string), новые поля `unp`, `created_by`; порядок полей; фикстуры.
- Twig/JS/CSS: `organization/form`, `_edit_modal`, `_organizations_table` (колонки, сортировка, `org_details` порядок и кнопки), `organization_hide/list`, `group/members`; `dashboard-orgs.scss`; `organization-modal.js`.
- Контроллеры/списки: сортировка состава группы, реестр скрытых, панель (удаление колонки industry из sort whitelist).
- `user-delete` flow: группы — переназначение/удаление; организации — автоматическое переназначение создателя текущему администратору (примечание на странице подтверждения).
- БД: миграция/alter без миграции продовых данных (UNP, created_by, rename courses_attended); зафиксировать порядок created_by → created_at/updated_at.
- e2e: dashboard-organizations, organization-hide, groups members, user-delete — обновить ожидания колонок/кнопок.
