## Why

Сценарии CRUD спецификации организаций требуют подсветки созданной/отредактированной организации в таблице панели после редиректа, а также автоматического раскрытия контактов этой организации. Механизм подсветки частично работает (CSS-класс добавляется, скролл выполняется), но отсутствуют: авто-раскрытие `<details>`, одноразовость подсветки (fade-out), и e2e-тест.

## What Changes

- **Авто-раскрытие `<details>`**: при подсветке организации автоматически раскрывать блок с контактами
- **Одноразовая подсветка**: подсветка исчезает через 4 секунды (CSS fade-out), не сохраняется между навигациями
- **Сохранение `highlight` в sort-ссылках**: макрос `sort_url` должен передавать параметр `highlight` (аналогично campaign)
- **E2e-тест**: Playwright-тест, проверяющий подсветку + авто-раскрытие после create и update

## Capabilities

### Modified Capabilities

- `organizations/crud` — исправление поведения подсветки (авто-раскрытие, fade-out, e2e)

## Impact

- `_organizations_table.html.twig` — добавить `open` на `<details>` при `highlight == organization.id`; исправить макрос `sort_url`
- `dashboard-orgs.scss` — добавить CSS-анимацию `@keyframes highlight-fade` для `.org-table__row--highlight`
- `organization-modal.js` — JS-удаление класса через timeout (fallback, если CSS-анимация не поддерживается)
- `e2e/tests/` — новые Playwright-тесты для проверки подсветки + авто-раскрытия
